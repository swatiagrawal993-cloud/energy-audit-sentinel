G0 / S0 State

Active Execution

107W – 162W

CPU, RAM, storage, and LED backlights fully energized. Maintained during practical lectures.

G0 / S0 Desktop Idle

Unattended Desktop

65W – 80W

OS running with no student active compute. Draws ~45% of peak wattage. Represents the primary target of waste reduction.

G1 / S3 Suspend

Low-Power Sleep

3.5W – 5.5W

CPU halted, display off. RAM energized to preserve session state. Cuts power draw by 95% during breaks.

G2 / S5 Soft-Off

Complete Shutdown

0.7W – 1.7W

Operating system halted; power rail disengaged except for real-time clock and network wake circuitry.
