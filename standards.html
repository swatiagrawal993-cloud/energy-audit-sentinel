Hardware Power States

ACPI Specifications & Empirical Benchmarks

Advanced Configuration and Power Interface (ACPI v6.5) standards applied to academic IT systems

State G0 / S0

Active Instructional Execution

107W – 162W

CPU cores, RAM buses, SSD drives, and LED monitor backlights operate at nominal thermal envelope. Maintained during practical shifts for compiling and programming.

State G0 / S0 (Idle)

Unattended Desktop Idle

65W – 80W

The operating system runs without active student input. Hardware draws roughly 45% of peak load. Represents the primary target of departmental waste elimination.

State G1 / S3

Low-Power Sleep (Suspend to RAM)

3.5W – 5.5W

The CPU is halted, auxiliary fans cease rotation, and display panels power off. Main system memory remains energized to preserve student IDE sessions.

State G2 / S5

Soft-Off / Complete Shutdown

0.7W – 1.7W

All main power rails disengage. Only the Real-Time Clock (RTC) and network Wake-on-LAN (WOL) circuitry receive standby trickle power.
